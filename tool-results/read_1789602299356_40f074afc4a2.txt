    11→    11→## 0. EXECUTIVE SUMMARY
    12→    12→
    13→    13→BedaanWaves is a NASDAQ-exclusive, machine-learned, multi-hierarchy scoring and ranking engine. Every coefficient in the production scoring path is **learned per symbol**, not per market snapshot. The system ingests OHLCV + fundamentals + macro + sentiment + AI signals, transforms them cross-sectionally within the ~5,600-symbol NASDAQ universe, aggregates them across a 4-level hierarchy (6 Dimensions → 44 Sub-Dimensions → 135 Aspects → 173 Sub-Aspects → 865+ Indicators), and produces a 0–100 overall score plus 6 dimension scores per symbol.
    14→    14→
    15→    15→The platform exposes this intelligence through a real-time, historically-deep UI featuring:
    16→    16→- Per-symbol historical score trends (overall + 6 dimensions) with multi-timeframe resolution
    17→    17→- Radar (spider) visualization of the 6-dimension profile with peer overlays
    18→    18→- **Embedded TradingView free-tier widgets** (price charts, heatmaps, screeners, calendars)
    19→    19→- A live rotating market ticker (price / Δ / overall score)
    20→    20→- A breaking-news ribbon for market-moving events
    21→    21→- Full NASDAQ universe coverage (~5,600 symbols)
    22→    22→- Score decomposition, peer comparison, alerts, watchlists, and export
    23→    23→
    24→    24→**Hard guarantees:**
    25→    25→- No hardcoded weights in the production scoring path.
    26→    26→- No mock, synthetic, or placeholder data — ever.

    49→    49→
    50→    50→### 1.3 Data Governance & Point-in-Time Correctness **(NEW)**
    51→    51→- **No lookahead bias:** every feature used at time `t` must have been observable at `t`. Fundamentals use `reported_at` timestamps, not `fiscal_period_end`.
    52→    52→- **Survivorship-bias-free:** delisted symbols remain in historical cross-sections until their delisting date.
    53→    53→- **Corporate-action adjusted:** all OHLCV adjusted for splits and dividends before indicator computation.
    54→    54→- **Trading halts:** flagged and excluded from cross-sectional ranking on halt days; last valid score carried forward with staleness flag.
    55→    55→- **Timezone discipline:** all timestamps stored in UTC; market events normalized to `America/New_York` for cross-sectional grouping.
    56→    56→- **Data lineage:** every metric value carries `(source, ingested_at, revision)` triple; any correction triggers downstream recomputation.
    57→    57→- **Data quality tiers:** `VALIDATED` · `PROVISIONAL` · `STALE` · `REJECTED`. Only `VALIDATED` enters training.

   185→   185→## 3. ZERO STATIC WEIGHTS — PER-SYMBOL LEARNING
   186→   186→
   187→   187→### 3.1 Core Principle
   188→   188→> **Every coefficient at every level is learned independently per symbol.**
   189→   189→
   190→   190→This is a **critical correction** over prior global-snapshot coefficient designs. At any given moment, symbol `AAPL` and symbol `NVDA` carry **different** coefficient vectors at L1, L2, L3, and L4 — because their historical score → return relationships differ.
   191→   191→
   192→   192→There are **no** market-wide coefficient snapshots in the production scoring path. Cold-start fallbacks (uniform `1/n`) are permitted only until per-symbol training data reaches `min_samples_for_training = 50`, and are always logged and auto-replaced.

   222→   222→## 4. LEARNING PIPELINE (Advanced)
   223→   223→
   224→   224→### 4.1 Training Data
   225→   225→Source: `raw_performance_scores`
   226→   226→Filter: `is_processed = True AND data_quality = 'VALIDATED'`
   227→   227→Max per training run: 5,000 most recent records **per symbol**.
   228→   228→Fields consumed: `dimension_scores`, `sub_dimension_scores`, `aspect_scores`, `sub_aspect_scores`, `target_return`, `target_volatility`, `target_price_change`, `captured_at`.
   229→   229→
   230→   230→### 4.2 Feature Engineering (50-Dim Vector, Per Sample)
   231→   231→- **Score stats (×4 levels):** 28 dims — mean, std, median, min, max, positive count, negative count
   232→   232→- **Temporal:** 5 dims — weekday, month, day, hour, is_weekend
   233→   233→- **Market context:** 4 dims — volatility, volume, price_change, market_cap
   234→   234→- **Padding:** zero-pad to fixed length 50
   235→   235→
   236→   236→### 4.3 Per-Symbol, Per-Level Model Training
   237→   237→For each `symbol ∈ NASDAQ` and each `level ∈ {dimensions, sub_dimensions, aspects, sub_aspects}`:
   238→   238→1. `X` ← feature matrix `(n_samples, 50)`
   239→   239→2. `y[i, k] = (|score[i][k]| / Σ_k |score[i][k]|) * target_return[i]`
   240→   240→3. `StandardScaler` on `X`
   241→   241→4. **Ensemble:** `RandomForestRegressor` + `GradientBoostingRegressor` + `HistGradientBoostingRegressor`, stacked via out-of-fold predictions
   242→   242→5. **Purged walk-forward cross-validation** with embargo (López de Prado, 2018) — prevents leakage from overlapping labels
   243→   243→6. Extract `feature_importances_` (RF) + `SHAP` mean |values| (GBM) → blended importance → map to key names → normalize to sum = 1.0
   244→   244→
   245→   245→### 4.4 Coefficient Normalization Contract
   246→   246→- All values ∈ [0, 1]
   247→   247→- Sum = 1.0 (rounding error distributed to largest weight)
   248→   248→- No negative values, no values > 1
   249→   249→- All-zero → uniform `1/n` (cold-start only, logged)
   250→   250→
   251→   251→### 4.5 Cadence & Persistence
   252→   252→- `retrain_interval_hours = 24`
   253→   253→- `min_samples_for_training = 50` (per symbol)
   254→   254→- `validation_split = 0.2` (plus purged walk-forward CV)
   255→   255→- History cap: 1,000 most recent samples per symbol
   256→   256→- Persistence: `joblib` + JSON per symbol (see §3.2)
   257→   257→- Hot-swap: newly trained coefficients take effect on the next scoring cycle, no restart
   258→   258→- **Model registry:** every coefficient version stored with `version_id`, `trained_at`, `metrics` (OOS R², IC, Sharpe of predicted portfolio), `data_hash`
   259→   259→
   260→   260→### 4.6 Drift Detection & Auto-Retraining Trigger **(NEW)**
   261→   261→- Population Stability Index (PSI) on feature distribution > 0.25 → drift alert
   262→   262→- Kolmogorov–Smirnov test on prediction distribution vs training → drift alert
   263→   263→- Rolling out-of-sample IC degradation > 30% → forced retrain
   264→   264→- Regime change detected via Hidden Markov Model (2-state: calm / stressed) → regime-specific re-weighting triggered
   265→   265→
   266→   266→### 4.7 Meta-Labeling **(NEW)**
   267→   267→Primary model predicts direction; secondary model (meta-labeler) predicts probability that the primary is correct. Meta-label probability is stored as `confidence` at the AI dimension and used to **down-weight** low-confidence predictions during aggregation.

   271→   271→## 5. SCORING ALGORITHM (V2 ENGINE)
   272→   272→
   273→   273→### 5.1 Dynamic Weight Resolution
   274→   274→```python
   275→   275→def _get_dynamic_weights(symbol, level):
   276→   276→    if _use_ml_coefficients and coefficient_service.is_model_trained(symbol, level):
   277→   277→        w = coefficient_service.get_coefficients(symbol, level)
   278→   278→        if validate(w) and abs(sum(w.values()) - 1.0) <= 1e-6:
   279→   279→            return w                       # per-symbol, ML-learned
   280→   280→    return uniform_fallback(level)         # cold-start ONLY, logged
   281→   281→```
   282→   282→
   283→   283→### 5.2 `score_market(asset_metrics)` — Step-by-Step
   284→   284→
   285→   285→**Input:** `asset_metrics: dict[asset_id, dict[db_field, float | None]]`
   286→   286→
   287→   287→**Step 1 — Cross-Sectional Percentile → Z → Score (NASDAQ peers, same day)**
   288→   288→For each `db_field` across all NASDAQ assets:
   289→   289→1. Collect values; `None` passes through unchanged.
   290→   290→2. Compute midrank (average rank for ties).
   291→   291→3. `p = (rank - 0.5) / n`
   292→   292→4. If `lower_is_better`: `p = 1.0 - p`
   293→   293→5. Clip `p` to `[1e-6, 1 - 1e-6]`
   294→   294→6. `z = Φ⁻¹(p)` (SciPy if available, else Abramowitz–Stegun)
   295→   295→7. `score = clamp(50 + 15·z, 0, 100)`
   296→   296→
   297→   297→**Step 2 — Coverage**
   298→   298→`coverage = (# present metrics) / |METRIC_UNIVERSE|`
   299→   299→
   300→   300→**Step 3 — L4 (Sub-Aspects)**
   301→   301→Store transformed score directly. Missing → `50.0` neutral (never 0).
   302→   302→
   303→   303→**Step 4 — L3 (Aspects) — per-symbol dynamic**
   304→   304→```
   305→   305→aspect_score[asp] = Σ_{sa ∈ asp} sub_aspect_score[sa] · w_symbol[sa]
   306→   306→                    ─────────────────────────────────────────────
   307→   307→                          Σ_{sa ∈ asp} w_symbol[sa]
   308→   308→```
   309→   309→
   310→   310→**Step 5 — L2 (Sub-Dimensions) — per-symbol dynamic**
   311→   311→`sub_dimension_score[sub] = coverage_weighted_mean(aspect_scores ∈ sub, w_symbol["sub_dimensions"])`
   312→   312→
   313→   313→**Step 6 — L1 (Dimensions) — per-symbol dynamic**
   314→   314→`dimension_score[dim] = coverage_weighted_mean(sub_dimension_scores ∈ dim, w_symbol["dimensions"])`
   315→   315→
   316→   316→**Step 7 — Overall — per-symbol dynamic**
   317→   317→```
   318→   318→overall = Σ_dim dimension_score[dim] · w_symbol[dim]
   319→   319→overall = clamp(overall, 0, 100)
   320→   320→```
   321→   321→> `DIMENSION_WEIGHTS` constant is **NOT** referenced. Only `w_symbol["dimensions"]`.
   322→   322→
   323→   323→**Step 8 — Grade & Signals**
   324→   324→| Score | Grade |
   325→   325→|-------|-------|
   326→   326→| ≥ 85 | STRONG_BULLISH |
   327→   327→| ≥ 70 | BULLISH |
   328→   328→| ≥ 55 | NEUTRAL |
   329→   329→| ≥ 40 | BEARISH |
   330→   330→| < 40 | STRONG_BEARISH |
   331→   331→
   332→   332→Signals: `strong_{dim}` if ≥ 80 · `positive_{dim}` if ≥ 60 · `weak_{dim}` if ≤ 20
   333→   333→
   334→   334→**Step 9 — Uncertainty & Stability (NEW)**
   335→   335→- **Conformal prediction interval:** 90% CI on overall score via split-conformal calibration.
   336→   336→- **Score stability index:** rolling 5-day std of overall score; low std = stable signal.
   337→   337→- **Circuit breaker:** if |Δscore| > 25 in one day without a corresponding price move > 15%, flag for manual review; do not silently propagate.
   338→   338→
   339→   339→**Output:** `HierarchicalScore` dataclass (all 4 levels + overall + grade + signals + coverage + CI + stability index).

   343→   343→## 6. TECHNICAL NORMALIZATION & BUNDLE SCORING
   344→   344→
   345→   345→### 6.1 Pre-Transform Rules
   346→   346→| Category | Examples | Normalization |
   347→   347→|----------|----------|---------------|
   348→   348→| Bounded | `rsi_14`, `stoch_k`, `mfi_14` | `clamp(v, 0, 100)` |
   349→   349→| Binary | `parabolic_sar_signal`, `ichimoku_score` | 75 if >0, 25 if <0, 50 if =0 |
   350→   350→| Lower-is-better | `atr_ratio`, `stddev_20` | `clamp(50 − 25·tanh(|v|/scale))` |
   351→   351→| Scaled | `macd_histogram`, `roc_12` | `clamp(50 + 25·tanh(v/scale))` |
   352→   352→
   353→   353→Scale factors live in `_TECHNICAL_SCALES` (e.g., `adx_14 → 40.0`, `mass_index → 25.0`).
   354→   354→
   355→   355→### 6.2 `score_technical_bundle(...)`
   356→   356→1. Flatten to `TECHNICAL_METRIC_FIELDS` (50 canonical fields).
   357→   357→2. Normalize each via `normalize_indicator_score`.
   358→   358→3. Regime-adaptive weights (learned **per symbol, per sub-dimension**):
   359→   359→   - `trend_factor = clamp(adx/40, 0, 1)`
   360→   360→   - `volatility_factor = clamp(volatility/0.50, 0, 1)`
   361→   361→   - Boost trend in strong trends; volume/volatility in high vol.
   362→   362→4. Base score = weighted mean using **per-symbol** sub-dimension coefficients.
   363→   363→5. Confluence bonus: rewards indicator agreement, ±10 max.
   364→   364→6. Divergence: +3 bullish, −3 bearish.
   365→   365→7. Final: `0.7·base + 0.3·confluence`.
   366→   366→
   367→   367→---
   368→   368→
   369→   369→## 7. AI DIMENSION
   370→   370→
   371→   371→### 7.1 Composite
   372→   372→```
   373→   373→AI_Score = ML_Predictions(w1) + Pattern_Recognition(w2) + Anomaly_Detection(w3)
   374→   374→```
   375→   375→Weights `w1, w2, w3` are **learned per symbol, per regime**:
   376→   376→| Regime | Adjustment |
   377→   377→|--------|------------|
   378→   378→| Bull | `pattern_recognition × 1.15` |
   379→   379→| Bear | `anomaly_detection × 1.20` |
   380→   380→| High Volatility | `ml_predictions × 1.10` |
   381→   381→| Sideways | cold-start balanced (logged) |
   382→   382→
   383→   383→Weights renormalized to sum = 1.0.
   384→   384→
   385→   385→### 7.2 ML Predictions
   386→   386→```
   387→   387→ml_score = 0.30·return_score + 0.25·confidence_score
   388→   388→         + 0.20·(100 − risk_score) + 0.15·win_rate_score + 0.10·model_confidence
   389→   389→```
   390→   390→- `return_score = 100·sigmoid(return_pct·50) − volatility_penalty`
   391→   391→- Confidence penalty: if `confidence < 65`, multiply by `(confidence/65)²`
   392→   392→- Technical alignment bonus: +5 for RSI/MACD alignment
   393→   393→
   394→   394→### 7.3 Pattern Recognition
   395→   395→```
   396→   396→pattern_score = Σ (prob · reliability · pattern_weight) / Σ pattern_weight
   397→   397→```
   398→   398→Pattern weights: reversal 1.2× · continuation 1.0× · candlestick 0.8× · anomaly 1.1×
   399→   399→Confluence: +5 for 2+ aligned · +10 for 3+ · +8 multi-timeframe
   400→   400→
   401→   401→### 7.4 Anomaly Detection
   402→   402→```
   403→   403→anomaly_score = 0.40·severity + 0.30·persistence + 0.20·(100 − market_impact) + 0.10·confidence
   404→   404→```
   405→   405→- `severity = min(100, |z|·20)` (cap ±5σ)
   406→   406→- If not anomaly: pull toward `50 + (score − 50)·0.5`
   407→   407→
   408→   408→### 7.5 Coverage & Staleness
   409→   409→- Coverage < 50% → `score = 50 + (score − 50)·coverage·2.0`
   410→   410→- Staleness > 5 trading days → `× 0.80`
   411→   411→

The relative weights of these 5 sub-dimensions within `macro` are **learned per symbol** — because a growth stock and a value stock respond differently to rate shocks.
